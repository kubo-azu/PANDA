# 🐼 PANDA: Phased ANalysis of DNA Amplicons 🧬

**PANDA** is a unified R/Shiny platform designed for the visualization and quantification of DNA methylation heterogeneity from bisulfite sequencing data. It seamlessly handles both **Sanger** (clonal) and **NGS** (amplicon) sequencing platforms.

Unlike traditional tools that only calculate average methylation rates per CpG site, PANDA focuses on **phasing information** analyzing methylation patterns on individual DNA strands. This approach enables the detection of **Allele-Specific Methylation (ASM)**, Imprinting, and heterogeneous epigenetic states.

**💡 This tool is readily accessible via a web browser at <https://huggingface.co/spaces/kubo-azu/PANDA>, requiring no local installation for end-users.**

## 🌟 Key Features

### Dual Mode Architecture:

-   **Sanger Mode**: Optimized for clonal sequences (TA cloning). Supports **FASTA**, **Multi-FASTA**, and `.ab1` (chromatogram) file inputs with trimming capabilities.
-   **NGS Mode**: Optimized for high-depth amplicon data (**FASTQ** and **FASTA**) generated by NGS. Features automatic dereplication and **full-read analysis** to visualize population structures accurately.

#### 🧫 Sanger Mode (Clonal Analysis)

-   **Standard Lollipop Plots**: Intuitive visualization of methylation status per individual clone. CpG sites are displayed sequentially for clear pattern recognition.
-   **ASM Clustering Heatmaps**: Automatically clusters clones into methylated/unmethylated groups using k-means (k=2). A fixed random seed is initialized prior to clustering to ensure computational reproducibility across different sessions.

#### 🧬 NGS Mode (Population Analysis)

-   **Methylation Histograms**: Instantly identify ASM by checking for bimodal distributions (peaks at 0% and 100%).
-   **Weighted Abundance Heatmaps**: Visualize the true proportion of alleles using read-count weighted heatmaps. The X-axis reflects the actual genomic distance (bp), allowing you to assess physical read coverage and drop-outs.
-   **Ranked Lollipop Plots**: Displays the sequence patterns of the most abundant unique alleles (Rank 1, 2, 3...). CpG sites are equally spaced for high visibility, combined with a read count bar chart.
-   **Flexible Paired-End Handling**: Supports both pre-merged reads (for full amplicon phasing) and unmerged R1/R2 pairs (automatically reverse-complements R2 for amplicons with unsequenced gaps).

#### 📌 Common Analytics (Both Modes)

-   **Difference Plots**: Comparative visualization of methylation differences between groups per CpG site.
-   **Global Methylation Bar Plots**: Overview of mean methylation levels across samples.
-   **Statistical Analysis**: Fisher's Exact Test (per-CpG site) and Mann-Whitney U Test (global distribution). Single-CpG p-values are automatically adjusted for multiple testing using the **Benjamini-Hochberg (FDR) procedure**.

### 🤖 Reference FASTA Auto-Correction
The strand direction of reference FASTA is automatically detected when the sequenced reads are derived from the opposite strand. The reverse complement reference is internally generated for accurate alignment.

### 🔍 In-silico Genotyping (Motif Filter):
PANDA includes a powerful filtering tool to perform in-silico genotyping and separate alleles based on sequence polymorphisms (SNPs) or complex haplotypes.

- **Haplotype Phasing**: By entering specific sequence motifs (or uploading a `.txt`/`.csv` list of complex haplotypes), PANDA extracts and analyzes only the reads or clones containing those exact motifs.
- **Allele Separation**: Highly effective for cleanly visualizing Allele-Specific Methylation (ASM) and discovering epigenetic defects like Loss of Imprinting (LOI).

### ⚖️ Quantification of Heterogeneity:

Calculates within-sample heterogeneity metrics (**PDR**, **qFDRP**, and **Epipolymorphism** values) to quantify epigenetic diversity beyond simple averages.

### 📄 Publication Ready:

One-click generation of high-resolution plots (PDF/PNG) and result bundles as a `zip` file.

## ⚙️ Alignment & Quality Control

PANDA is designed to be a lightweight, standalone application that runs entirely within R, eliminating the need for complex external command-line dependencies.

### 1. Alignment Strategy (No External Aligners Required)
Unlike whole-genome bisulfite tools (e.g., Bismark, Bowtie2) that require genome indexing and are overly complex for amplicon data, PANDA is specifically optimized for targeted sequencing. 
* It utilizes **Local Pairwise Alignment** via the robust `Biostrings` R package.
* An *in silico* C-to-T conversion is performed on both the reference amplicon and the reads prior to alignment, ensuring accurate, unbiased mapping of bisulfite-treated sequences.
* **Highly Stringent Scoring:** To prevent artefactual gapping and ensure exact positional coordinate mapping of CpG sites, alignments are performed using strict Smith-Waterman parameters (match = 1, mismatch = -3, gap opening = -10, gap extension = -4).

### 2. Quality Filtering (Biological QC)
To seamlessly support both NGS data (FASTQ) and Sanger sequencing data (FASTA), PANDA **does not rely on Phred Base Quality scores** for filtering. Instead, it employs strict, biologically relevant filtering criteria based entirely on the alignment results:
* **Sequence Identity:** Reads must match the reference sequence above a user-defined threshold (Default: ≥ 90%).
* **Bisulfite Conversion Rate:** PANDA calculates the conversion efficiency of non-CpG cytosines for *each individual read*. Reads with incomplete conversion (Default: < 95%) are automatically excluded to prevent false-positive methylation calls.

*(Note: If quality trimming based on Phred scores or UMI deduplication is required for your specific NGS workflow, we recommend pre-processing your FASTQ files with standard tools like `fastp`, `Trimmomatic`, or `UMI-tools` before uploading the clean reads to PANDA.)*


1. Clone this repository

   ```bash
   git clone [https://github.com/kubo-azu/PANDA.git](https://github.com/kubo-azu/PANDA.git)
   ```

2. Navigate to the cloned directory in R, or open the `PANDA.Rproj` file in RStudio

   ```r

   renv::restore()
   ```

4. Run the application

   ```r
   shiny::runApp()
   ```


## ⚠️ Input Data Specifications

### File Size Limit

PANDA supports file uploads up to 300 MB per session. For larger FASTQ files, please downsample or split them prior to upload.

### Reference Genome

**CRITICAL: Do NOT upload whole genome files (e.g., hg38).** The alignment algorithm is optimized for short amplicons.
We recommend two methods to prepare your Reference FASTA:

#### Method A: Using primers information (especially recommended for NGS Mode refarence)

1.  Use tools like [UCSC In-Silico PCR](https://genome.ucsc.edu/cgi-bin/hgPcr).
2.  Paste your forward and reverse primers.
3.  The tool will extract the exact amplicon sequence (including necessary flanking regions). Save this output as `.fasta`.

#### Method B: Manual extraction

1.  Search your target gene in [UCSC Genome Browser](https://genome.ucsc.edu) or [NCBI](https://www.ncbi.nlm.nih.gov/home/genomes/) web sites.
2.  Zoom in to your PCR amplicon region
3.  Manually copy the sequence, ensuring you include **30-50bp flanking regions** around your primers.
4.  Save as `.fasta`.
*(Note: Due to PANDA's strand detection module, you do not need to worry about whether your FASTA sequence is the forward or reverse strand.)*

### Sanger Data
-   **Trimming**: We recommend trimming primer regions using chromatogram viewer softwares and subsequently save as FASTA.

### NGS Data
-   **Formats**: FASTQ (`.fastq`, `.fq`, `.fastq.gz`, `.fq.gz`) or FASTA (`.fasta`, `.fa`)
-   **Supported Read Modes & Best Practices for Paired-End Data**: 
    To get the cleanest and most accurate results, please choose the correct mode based on your amplicon length:
    1.  **Merged Reads (Highly Recommended)**: Please merge your Paired-End reads (R1/R2) using external tools (e.g., [fastp](https://github.com/OpenGene/fastp)) before uploading. Select the `Single / Merged` mode. This ensures the highest accuracy across the entire amplicon.
    2.  **Single-End (Read 1 Only) (Recommended)**: If your amplicon is short and completely covered by Read 1 (e.g., 150bp read for a 180bp amplicon), uploading ONLY the Read 1 file in `Single / Merged` mode is the best practice. It prevents double-counting and minimizes noise from the lower-quality R2.
    3.  **Unmerged Pairs (R1 & R2)**: *Use ONLY for long amplicons with an unsequenced gap in the middle.* PANDA internally pairs the R1 and R2 reads, rigorously filters out pairs with poor quality, and **visualizes them as a single contiguous line bridging the unsequenced gap to prove long-range phasing.** If you use this mode for short, overlapping amplicons, PANDA will double-count identical molecules, and the higher error rate of R2 might cause the reads to fail the quality filter.
-   **Trimming**: We strongly recommend trimming adapters and primers prior to analysis.

## 📊 Outputs & Interpretation

PANDA provides comprehensive outputs across different tabs.

### 1. NGS Amplicon Mode
Designed for high-depth amplicon sequencing.

- **Batch Summary**: Overview plot and table to quickly check total reads, valid reads, and mean methylation across all files.
- **ASM Profile (Main Tab)**:
    - **Heterogeneity Metrics**: Quantitative scores (PDR, Epipolymorphism, qFDRP).
    - **Methylation Distribution (Histogram)**: The most critical plot for ASM detection. Bimodal peaks at 0% and 100% indicate ASM or Imprinting.
    - **Abundance Heatmap (Weighted)**: Read-count weighted heatmap. The X-axis reflects **actual genomic distance**, allowing you to evaluate physical read drop-outs.
- **Top Sequences**: 
    - **Ranked Lollipop Plot**: Shows top abundant unique alleles. Unlike the heatmap, CpG sites are **equally spaced** for maximum visual clarity, paired with a read count bar chart. Ideal for presentations.
- **Statistics & Alignments**: Detailed CpG tables, Read QC, and pairwise text alignments (perfect for confirming Motif Filter targets).

### 2. Sanger Mode
Designed for detailed analysis of clonal sequences (e.g., TA cloning).

- **Lollipop Plot**: Standard visualization (1 line = 1 clone). CpG sites are equally spaced. Y-axis displays clone names.
- **Heterogeneity & ASM**: Includes the k-means (k=2) **ASM Heatmap** to automatically split methylated and unmethylated clones, and heterogeneity scores.
- **Individual Details (Batch Mode)**: Allows you to upload multiple FASTA files at once, view a global summary, and select any single sample from a dropdown to inspect its full Lollipop plot and QC metrics.
- **Sequence Info & Alignments**: Check Identity %, Conversion %, and raw text alignments for every single clone.

### 3. Group Comparison (Both Modes)
Statistical comparison between two user-defined groups (e.g., WT vs. KO). Includes **Difference Plots**, **Global Mean Comparison**, and Statistical Tests (Mann-Whitney U, Fisher's Exact). To ensure statistical rigor, all per-CpG p-values include **FDR correction (Benjamini-Hochberg)**, which are directly accessible in the downloadable results table.

## 📐 Heterogeneity Metrics Definitions

PANDA calculates advanced metrics to quantify disorder in methylation patterns. These algorithms are based on [Scherer et al., Nucleic Acids Res, 2020](https://doi.org/10.1093/nar/gkaa120).

-   **PDR (Proportion of Discordant Reads)**: The percentage of reads that are locally discordant (i.e., contain both methylated and unmethylated CpGs within the same read). High PDR indicates stochastic or disordered methylation turnover.
-   **Epipolymorphism**: Calculated based on the probability of observing specific epialleles (patterns of 4 consecutive CpGs). High values indicate a diverse population of methylation patterns.
-   **qFDRP (quantitative Fraction of Discordant Read Pairs)**: Measures the dissimilarity between randomly chosen pairs of reads. A high qFDRP indicates that the population contains diverse methylation states (high heterogeneity) rather than a uniform pattern.

### 🧬 Tutorial 1: NGS Mode Experience

PANDA's NGS mode is optimized for high-depth amplicon sequencing. Start by navigating to the **NGS Mode** tab and uploading the Reference FASTA (`PANDA_Demo/NGS/Reference/NGS_Ref_Targets.fasta`).

#### Experiment A: Detect Allele-Specific Methylation (ASM)
*Demonstrates PANDA's ability to visualize inter-molecule heterogeneity that bulk averaging tools miss.*
1. Select Target: `mm10_H19_DMR`.
2. Select Read Mode: **`Single / Merged`**.
3. Upload FASTQ files from the `ExpA_ASM` folder (`Normal` and `LOI` replicates).
4. Click **[Run Batch Analysis]**.
5. Go to **"Single Sample Analysis" > "ASM Profile"** tab.
   * **Result**: "Normal" samples show an average methylation of ~50%, but the histogram reveals a classic Bimodal Distribution (peaks at 0% and 100%), proving the coexistence of distinct maternal and paternal epialleles. "LOI" (Loss of Imprinting) samples show a Single Peak at 100%, indicating a loss of epigenetic heterogeneity.

#### Experiment B: Haplotype Phasing from Heterozygous Mixture (Motif Filter)
*Demonstrates how to separate alleles in silico from a 50:50 mixed sample using an underlying genetic variant (1-bp SNP).*
1. Click **[Clear Files]**. Ensure Read Mode is still set to **`Single / Merged`**, and the target is `mm10_H19_DMR`.
2. Upload the FASTQ files from the `ExpB_Phasing` folder (These simulate 50:50 heterozygous mixed patient samples).
3. Click **[Run Batch Analysis]** *without* entering any motif first.
   * **Result**: In the "ASM Profile" tab, you will see a Bimodal Distribution (peaks at 0% and 100%), as both methylated and unmethylated alleles are mixed in the sample.
4. In the **"Motif Filter"** box on the sidebar, type the sequence for Motif A.
   -> Motif A (Isolates Unmethylated allele): TGTATAAATGATTGATTTTTT
   -> Motif B (Isolates Methylated allele)  : TGTATAAATGGTTGATTTTTT
5. Click **[Run Batch Analysis]** again.
   * **Result**: PANDA dynamically filters the mixed sample and extracts only Haplotype A. The histogram instantly switches to a single peak at ~0% (pure unmethylated allele). 
6. Change the Motif Filter to the sequence for Motif B and re-analyze. The population instantly switches to ~100% (pure highly methylated allele). You successfully phased the DNA methylation haplotypes without physical separation!

#### Experiment C: Group Comparison (TF Footprint Remodeling)
*Highlights PANDA's power at single-base resolution compared to traditional global averaging.*
1. Click **[Clear Files]** and change Reference Target to `mm10_Nanog_Promoter`.
2. Select Read Mode: **`Single / Merged`**.
3. Upload FASTQ files from the `ExpC_Group` folder.
4. Click **[Run Batch Analysis]**.
5. Go to the **"Compare Groups"** sidebar, assign WT replicates to Group 1 and KO replicates to Group 2, then click **[Run Comparison]**.
6. Check the **"Group Comparison"** tab.
   * **Result**: If you look at the global mean methylation, WT and KO appear nearly identical (both ~85%). However, PANDA's per-CpG **Difference Plot** beautifully captures a dynamic epigenetic remodeling event. It reveals a Transcription Factor (TF) footprint shift, showing a mix of locally up-regulated (red) and down-regulated (blue) CpG sites within the exact same region.

*(Note: If you have long unmerged amplicons with an unsequenced gap, you would select the `Unmerged Paired-end (R1 & R2)` mode and register the forward and reverse reads as a pair instead of uploading them directly to the batch.)*

### 🧫 Tutorial 2: Sanger Mode Experience

PANDA's Sanger mode provides deep inspection of clonal sequences (e.g., TA cloning). Navigate to the **Sanger Mode** tab and upload the Reference FASTA (`PANDA_Demo/Sanger/Reference/Sanger_Ref_Targets.fasta`).

#### Experiment A: Detailed Clone Analysis (Single Mode)
1. Select **"Single Sample"** in the sidebar.
2. Upload `Sanger_Single_H19_ASM.fasta` from the `Sanger/Single/` folder.
3. Click **[Run Single Analysis]**.
4. Check the **"Heterogeneity & ASM"** tab.
   * **Result**: PANDA automatically performs K-means clustering to separate the 16 clones into distinct Methylated and Unmethylated clusters, instantly proving the presence of ASM visually.

#### Experiment B: Motif Filter & Batch Processing (Multi Mode)
*Process multiple Sanger cloning experiments simultaneously and isolate specific haplotypes from a heterozygous mixture.*
1. Select **"Multi-Sample Comparison"** in the sidebar.
2. Upload all FASTA files from the `Sanger/Multi/ExpB_Phasing/` folder. (These files contain a mix of clones from both alleles).
3. Type the **21-bp** Motif A sequence into the **"Motif Filter"** box.
   -> Motif A (Isolates Unmethylated allele): TGTATAAATGATTGATTTTTT
   -> Motif B (Isolates Methylated allele)  : TGTATAAATGGTTGATTTTTT
4. Click **[Run Batch Analysis]**.
   * **Result**: Only the clones containing the specified SNP are perfectly extracted across all files. The Lollipop plots and overall statistics in the **"Batch Summary"** tab are instantly updated to reflect only this specific unmethylated allele.

#### Experiment C: Statistical Comparison in Sanger Mode (Multi Mode)
1. Click **[Clear Files]**. Ensure the Reference Target is changed to `mm10_Nanog_Promoter`.
2. Upload all FASTA files from the `Sanger/Multi/ExpC_Group/` folder.
3. Click **[Run Batch Analysis]**.
4. Go to the **"Compare Groups"** section in the sidebar. Assign WT clones to Group 1 and KO clones to Group 2, and click **[Run Comparison]**.
   * **Result**: PANDA seamlessly performs statistical comparisons for Sanger sequencing data. The Difference Plot will reveal the exact same single-base TF footprint shift (WT vs KO) observed in the NGS data, proving PANDA's robust performance even with small clonal sample sizes.
